# WireGuard VPN v1.0 — Golden

First release of WireGuard VPN, the StreamHub-only edition of HAIBOX WireGuard v6.8.

- Same wizard, Web UI, apply with rollback, persistence and terminal menu as HAIBOX WireGuard v6.8.
- Publishes one Haivision StreamHub with the same port set as HAIBOX WireGuard (public and WireGuard hairpin DNAT).
- Overview shows the WireGuard Router and Remote VPN Client peers, StreamHub status and Router/StreamHub/Other VPN traffic.
- Extra Port Forwarding, DMZ, Domain, VPN Profiles and Remove All are included.
- WireGuard logo and red accents in the Web UI.

Install on a Debian or Ubuntu VPS as root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/simonemessina92/wireguard-VPN/main/install.sh)
```
